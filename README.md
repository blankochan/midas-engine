# Welcome to Midas Engine!

Midas Engine is a PvP automation game where you and a rival self-replicating AI compete over the ressources of a planet, eventually incapacitating your enemy and the planet's ressources by turning the whole thing into gold.

We aim to make a fun, competitive game where the usual woes of PvP automation are fixed by bringing more attention to what is usually a second thought.
